# Portfólio QA 

## Competências
- Testes de API com Postman
- Scripts de teste em JavaScript (pm.test)
- Documentação de casos de teste
- Git e GitHub

## Projetos

### 1. Testes de API com Postman
- API testada: https://jsonplaceholder.typicode.com (API pública)
- Cobertura: GET, POST, PUT, DELETE
- Validações: status code, tempo de resposta, corpo da resposta
- Arquivos: `postman/`

### 2. Documentação de testes
- Casos de teste com passos, resultado esperado e resultado obtido
- Arquivos: `documentacao/`
